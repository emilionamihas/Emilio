# WiA — Traductor de Terminal

Página estática de broma (sin backend, sin dependencias) que "traduce" comandos de terminal comunes al estilo del personaje WiA: un desarrollador ficticio con confianza absoluta y cero competencia real.

Es sátira. No representa el comportamiento del asistente que la construyó ni debe usarse como referencia técnica real.

## Uso

Abrí `index.html` directamente en el navegador, o serví la carpeta con cualquier servidor estático:

```
npx serve wia-app
```

No requiere build ni instalación de paquetes.
